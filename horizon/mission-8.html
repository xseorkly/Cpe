Les pièces du scénario

Enveloppe 1 8h05 : AED D absent au créneau T3 ; A, B et F disponibles pour les postes R C B. Enveloppe 2 8h15 : PP signale des retards sans cause déterminée. Enveloppe 3 8h25 : AED transmet une confidence de possible harcèlement avec élève inquiète. Enveloppe 4 8h35 : parent demande un entretien immédiat sur un ancien incident. Enveloppe 5 9h00 : direction demande point factuel. Informations conditionnelles : si recherche disponibilités T3, montrer A/B/F ; si demande confrontation, arrêter pour protéger ; si conclusion hâtive sur assiduité, demander les faits. Grille observateur : faits et hypothèses ; protection prioritaire ; compétences et acteurs ; communication ; trace/suivi ; révision, chacun 0 absent, 1 partiel, 2 démontré en simulation.
