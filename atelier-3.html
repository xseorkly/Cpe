Les documents de l'atelier

Toutes les pièces ci-dessous sont fournies intégralement. Utilisez les boutons d'impression si vous travaillez sur papier.

DOCUMENT 1

Présentation des six AED

A connaît bien l’accueil ; B débute et souhaite un tutorat ; C demande un outil commun de transmission ; D questionne l’équité des postes du midi ; E demande des consignes plus explicites ; F transmet irrégulièrement ses interventions.

DOCUMENT 2

Deux messages reçus

D : « Peut-on revoir ensemble les critères d'affectation du midi ? » B : « Quand le CPE est en entretien, je ne sais pas à qui transmettre les retards. Chaque collègue me donne une réponse différente. »

DOCUMENT 3

Deux comptes rendus du même incident

F : « Élève agressif, incident grave ». C : « Deux élèves ont élevé la voix devant la restauration ; séparés sans blessure constatée ; direction informée ». La différence de formulation doit être discutée, et les faits vérifiés.

DOCUMENT 4

Cartes pour la simulation

CPE : mener un entretien de régulation factuel avec F. F : vous pensiez qu'un collègue transmettrait l'information ; vous acceptez une clarification, mais contestez une accusation générale. Observateur : relever l'écoute, le rappel des règles et la conclusion. Réunion : A défend les habitudes ; B demande un exemple ; C une transmission unique ; D un critère d’équité ; E une formation ; F craint une surcharge.

DOCUMENT 5

Trame de réunion à compléter

Objectif commun : ____ ; ordre du jour : transmissions, organisation de la pause méridienne, accueil des nouveaux AED ; décisions : ____ ; responsable : ____ ; date de vérification : ____.
